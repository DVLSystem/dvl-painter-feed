# DVL Painter Feed — Clean v1.1 Top 5

A clean rebuild intended to replace the mixed V3–V8 files.

## Included
- FEED + SAVED only (no gallery code)
- YouTube + selected website sources
- 6-hour GitHub Actions refresh
- Last update time
- Search / painter / source / time / tag filters
- Browser-based Painter Manager
- Optional GitHub publish using a fine-grained PAT (token is never stored)
- Automatic preservation of the last good source data when a refresh fails
- No demo feed entries

## Important files
- `index.html`, `app.js`, `styles.css`
- `data/painters.json`
- `data/feed.json` — generated by the workflow; do not edit manually
- `data/meta.json` — generated by the workflow
- `scripts/update_feed.py`
- `.github/workflows/update-feed.yml`

## First run
After uploading the complete clean build, open:
Actions → Update Painter Feed → Run workflow

The workflow installs `yt-dlp`, collects current content and writes feed/meta data.

## Web upload note
GitHub's web uploader may not preserve a hidden `.github` folder reliably. Create or replace
`.github/workflows/update-feed.yml` manually in the GitHub web editor if necessary.

## GitHub PAT for Painter Manager
Use a fine-grained token limited to this repository with:
Repository permissions → Contents → Read and write

The token is sent directly from your browser to GitHub's API for the publish request and is not persisted by this app.
